Welcome in NameSurfer
The program generates a popularity graph for names given to children in American families between 1900 and 2010.
You can check a name's popularity by entering name or names in English (separated by a space) into the text field and clicking the button "Graph" or pressing key "Enter". If the name is in the database, a popularity graph will appear; otherwise, the program will display a message stating that the name\s was\were not found.
Click the button "Clear" to clear all graphs from the screen.
To remove the graph for a specific name\s, type the word "сlear" and the needed name or names (separated by a space),
for example "clear alex" or "clear alex omar bil" into the text field and press key "Enter".
With button "Delete" will be deleted all names printing in text field, use button "Delete" without command-word "сlear".
If the graph\s of checked name\s is\are at the canvas, it\they will be removed; otherwise, the program will display a message stating that graphs for certain names were not found.
