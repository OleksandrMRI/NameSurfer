Welcome in NameSurfer
The program generates a popularity graph for names given to children in American families between 1900 and 2010.
You can check a name's popularity by entering name or names in English (separated by a space) into the text field and clicking the button "Graph".
If the name is in the database, a popularity graph will appear; otherwise, the program will display a message stating that the name was not found.
Click the button "Clear" to clear all graphs from the screen.
To remove the graph for a specific name, type the word "сlear" and the needed name or names (separated by a space),
for example "clear alex" or "clear alex omar bil" into the text field and press Enter.
